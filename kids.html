Smart shopping for kids

  • Check the size chart on each store. Kids sizes can run small, so size up if they're between sizes.
  • Look for age labels on toys, and skip small parts for children under 3.
  • Order early for holidays. Temu and AliExpress can take 1 to 3 weeks; Amazon and Walmart are usually faster.
  • Read reviews and return policies before you check out.
